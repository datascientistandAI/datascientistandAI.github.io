Design-Assist — Automated BRS/SRS Documentation

MTN Cameroon · Software Engineering Internship

Requirements Extract Validate Export

Challenge

Built a Django application that turns raw business requirements into structured Business/Software Requirements documents (BRS/SRS) — upload requirements, extract the relevant content, generate structured sections, then validate and organize them before export.

Solution

Owned backend development in Django — views, templates, data flow, and application logic — integrated with Azure Document Intelligence for extraction and a prompt-assembly layer that turns extracted content into structured requirement sections.

Outcome

Implemented authentication with login/logout tracking, activity logging for auditability, requirement validation, and one-click export to Word and PDF.

Engineering Practice

The hardest part was reliably turning unstructured requirements into structured BRS/SRS output — I traced inputs through extraction, prompt assembly, and generation to isolate where the pipeline broke, rather than trusting generated output at face value. Also produced UML diagrams and technical documentation for the system.
