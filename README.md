# Boris Emakam Garcial — Professional Portfolio

Static portfolio website for Boris Emakam Garcial, covering software development, IT support, and machine-learning research.

## Publish with GitHub Pages

1. Create a public GitHub repository named `datascientistandAI.github.io`.
2. Upload the contents of this directory to the repository root. `index.html` must remain at the root level.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, then select the `main` branch and the `/(root)` folder.
5. The portfolio will be available at `https://datascientistandAI.github.io` after GitHub finishes deploying it.

## Local preview

Open `index.html` in a browser, or run a local static server from this directory.
